# Battleship

A browser Battleship game in HTML, CSS, and JavaScript. Two players can be on **different Wi‑Fi** (different houses, phones, or cities). They must both open **the same public website**, then use a 4-letter room code.

Opening `index.html` as a file or using `localhost` will not work for a friend on another network. Put this folder on any free static host and share that URL.

## Play

1. Publish this folder (Netlify Drop, GitHub Pages, or any web host) and send your friend the https link.
2. Both of you open that link.
3. One player taps **Create room** and sends the code.
4. The other types the code and taps **Join**.
5. Place ships (or **Random fleet**), then **Ready**, and take turns firing.

Classic 10×10 fleet: Carrier 5, Battleship 4, Cruiser 3, Submarine 3, Destroyer 2.
